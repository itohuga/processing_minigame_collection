## 難しかった点・学んだこと

### 難しかった点

> 4つのミニゲームを1つにまとめるというのが難しかった。
> 最初、自分が描いたイラストを使おうとしたが、バグりまくったのでやめた。
> AIがちゃらんぽらんな回答ばっかだったので思うようにいかなかった。

### 学んだこと

> キャラクターの動きに合わせてカメラのスクロールも進んでいく機構が作れた。
> AIを使う際、最初はgeminiを使ってプログラムの質問をしていたが、ちゃらんぽらんだったのでClaudeというAIを使用した。そしたら、一瞬で作ってほしい完ぺきな状態のプログラムが提出されたので、シンギュラリティは近づいているのだなと感じた。

## 生成AIの利用について

### 使用した生成AI

* Claude(プログラム全般)
* gemini(エラー作業、お話)

### 生成AIを使用した場面

* プログラムのエラーの原因を調べた
* プログラムの一部を作成する際の参考にした
* プログラムの改善案を考えるために使用した

### 生成AIに入力した内容

> 「エンターキーを押すと、主人公はレールに沿って加速しながら進んでいきます。」

> 「以上の要素は、すべて盛り込むこと。エラー(構文エラー、動かない、要素がない等)のない完璧な状態で私に見せること。プログラムに何かしらのエラーが発覚したならば、すぐに修正すること。実際の画面ではエラー表示は出ずとも、その行動をしているのにうまく認識してくれないことも多々あります。一度すべての会話を見直し、私が何を生成してほしくて、どのようなテーマがあるのか考えること。本当にこれでよいか、プログラムを提示する前にしっかりと吟味すること。」

### 生成AIから得たものをどのように利用したか

> 生成AIが提示したプログラムを使用し、変更したい箇所を修正しました。

### 生成AIの回答を確認・修正したこと

> 生成AIが提示したコードを実際にProcessingで実行し、エラーが発生した部分を修正しました。
> 動作を確認しながら、自分の目的に合わない処理を変更しました。

## 実行方法

### Processingで実行する場合

1. GitHubからリポジトリをダウンロードする
2. sketchフォルダをProcessingで開く
3. `.pde` ファイルを開く
4. Processingの「実行」ボタンを押す
